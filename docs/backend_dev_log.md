# 后端开发思路与日志（用户管理与数据隔离）

## 目标
- 实现用户注册、登录、鉴权（JWT）
- 每个用户只能访问和管理自己的数据，实现数据隔离
- 使用 SQLite 作为数据库，后端框架为 FastAPI

---

## 1. 数据库设计

### 1.1 用户表（users）
| 字段名      | 类型         | 说明         |
| ----------- | ------------ | ------------ |
| id          | INTEGER      | 主键，自增   |
| email       | TEXT         | 用户邮箱，唯一|
| password    | TEXT         | 密码哈希     |
| created_at  | DATETIME     | 创建时间     |

### 1.2 图片表（images）
| 字段名      | 类型         | 说明         |
| ----------- | ------------ | ------------ |
| id          | INTEGER      | 主键，自增   |
| user_id     | INTEGER      | 所属用户ID   |
| url         | TEXT         | 图片地址     |
| prompt      | TEXT         | 生成提示词   |
| created_at  | DATETIME     | 创建时间     |

- user_id 外键关联 users.id，实现数据隔离

---

## 2. 用户管理开发流程

### 2.1 用户注册
- 接口：POST /api/register
- 输入：邮箱、密码
- 流程：
  1. 检查邮箱是否已注册
  2. 密码加密存储（使用bcrypt）
  3. 创建用户记录
  4. 生成JWT Token返回

### 2.2 用户登录
- 接口：POST /api/login
- 输入：邮箱、密码
- 流程：
  1. 校验邮箱和密码
  2. 生成JWT Token返回

### 2.3 鉴权与数据隔离
- 所有需要登录的接口需校验JWT
- 查询、操作图片数据时，均限定user_id为当前用户
